# Flip Radar

Upcoming limited sneaker and streetwear drops, ranked by expected resale profit after fees.
Live at https://flipradar.techboy.dev

- `index.html` – the whole app (static, no build step).
- `data/drops.json` – the drop list. A Claude scheduled task ("Flip Radar daily scout") rewrites it every morning and pushes to `main`; GitHub Pages redeploys automatically.

Resale numbers are estimates, not financial advice.
